Copia de seguridad

Esta app guarda todo automáticamente según el entorno donde se ejecute (mira el indicador arriba a la derecha). Aun así, exporta una copia JSON de vez en cuando — es la única forma de mover el portfolio entre ordenadores o compartirlo con el equipo.

Mantenimiento

Útil si el Panel no coincide con las máquinas guardadas. Vuelve a leer todas las máquinas del almacenamiento y recalcula el índice.
